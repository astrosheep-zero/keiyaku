# Invocation Facet

`Keiyaku` composes independent product surfaces for a caller that has an
invocation directory and environment rather than resolved product coordinates.
It captures those explicit inputs without observing the filesystem or reading
ambient process state. Each operation resolves its invocation scope anew; the
facet keeps no persistent authority, observation cache, or separate result model.
Its operations return native owner values and preserve owner refusal, retry,
cancellation, and observation semantics. A single described verb surface offers
both typed methods and generic execution over the same caller boundary. The
facet also owns the shared interpretation of returned and thrown outcomes for
adapters; this classification does not replace or alter the native answer.
Structural descriptions expose wire inputs and complete owner results alongside
their owner-declared normal subsets and progress, without validating trusted
owner values as they flow through execution. Routing composes these descriptions
without narrowing the native return value. Every
described verb's output type is its producing owner's schema output; native
process-local capabilities stay outside that wire description. Each result uses
the native owner's single object answer. Invocation context can
accompany text rendering without being echoed in that answer, and adapters
consume the owner's outcome judgment rather than reconstructing authority from
omitted implementation evidence.

An owner supplies each described verb's business input as one object, including
operations with no business fields. Typed calls and generic execution cross that
same boundary, with the same business inputs and optional execution controls.
Omitted business input has the same meaning on both faces when the operation
accepts an empty input. Cancellation belongs to execution rather than business
intent; an already-cancelled invocation stops before coordinate discovery or
product observation. After entry, cancellation reaches native owners that support
it without inventing interruption for other operations. Pure caller constraints
are declared with their producing owner
and checked before coordinate discovery, World establishment, or product
observation; validation never resolves a product merely to judge input shape.
Contradictory caller intent remains usage, distinct from an execution failure.

MCP publishes the facet's operations subject to the administration and raw-import
exclusion owned by [cli.md](cli.md). Structured output is reserved for routing
operations: it projects normal owner answers onto compact facts needed to choose
the next call. Every normal answer of such a tool carries that projection,
including an answered negative verdict. Native callers and CLI JSON retain the
full owner value. Guidance and Debt detail return complete unclipped text at the
transport edge. These projections supply no new classification or authority.
Error results are text led by their classification and remain text-only, including
their structured failure projection. Runtime recovery guidance uses MCP calls in
MCP syntax, derived from the same native recovery facts used by other surfaces.
An unsatisfied verification verdict is an answered negative, distinct from an
operation failure, and is not a transport error. Published names are safe
for model APIs and are the only callable transport names. Read-only annotations
identify reads; destructive annotations identify destruction alone, not ordinary
writes.

Delivery has one invocation intent, with an explicit read-only observation mode.
The facet validates incompatible observation and mutation intents before resolving
coordinates or observing any product, then selects exactly one native owner.
Observation uses the dedicated Contract preview operation; submission uses native
delivery admission. Both return their existing native answers without an envelope,
and the selected mode supplies presentation context without becoming authority.

The invocation World is distinct from an explicitly selected Contract Repo:
selecting a Repo never retargets the World. The facet adapts caller-supplied
coordinates, Contract selection, and environment-derived caller and
initiator attribution. These declarations are not authentication. Akuma
execution directories remain independent of Contract association. Product
surfaces neither depend on the facet nor require it to operate.

Ambiguous native harness caller declarations are refused rather than guessed.
The diagnostic names every conflicting environment variable so the caller can
identify the competing declarations without disclosing their values.

Debt invocation resolves the caller's World independently of a selected Repo.
World-only Debt mutations and Akuma progress reports do not accept repository
selection at the standalone transport edge.
Every Debt catalogue covers that World's flat ledger. Creation alone
establishes a missing World.
Debt reads retain native absence and refusal distinctions; listing defaults to
open work.

Each list and addressed status operation selects one producing owner before
observation. The independent selector-free Kanshi read owns the World report;
status requires one complete Contract or Akuma identity and never falls back to
World observation. A missing Contract is refused; a failed exact Contract read
is an operational failure. Catalogues identify their Contract, Akuma-instance, akumaName, or Debt family even
when empty or unavailable. Instance caller selection and Debt lifecycle selection
belong only to their respective owners and precede bounding. Invocation caller
scoping selects only this invocation's environment-derived identity; absent or
ambiguous identity is usage. The native Akumas composition independently retains
explicit caller selection. There is no
cross-family catalogue, category status, or plural status result.

Guidance selection reuses the Contract context resolver when omitted. Singular
detail selects a Contract or Debt; plural detail selects Debts only, including a
single-member batch. Invalid or mixed selection refuses before product reads.
Debt partial absence preserves independently readable peers in the native answer
while refusing the invocation. A named CLI
address is acquired at the asynchronous process edge, then dispatched as the
resolved family's ordinary exact operation. A Contract wait and an Akuma wait
remain separate and a mixed wait is refused before observation. History selects
one subject. A caller-input error is distinguishable from an owner refusal or
an unexpected failure, and adds no authority to the facet.

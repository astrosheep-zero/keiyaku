# Invocation Facet

`Keiyaku` composes independent product surfaces for a caller that has an
invocation directory and environment rather than resolved product coordinates.
It captures those explicit inputs without observing the filesystem or reading
ambient process state. Each operation resolves its invocation scope anew; the
facet keeps no persistent authority or observation cache. Its operations return
native owner values, except for its cross-product wait composition, and preserve owner refusal, retry,
cancellation, and observation semantics. A single described verb surface offers
both typed methods and generic execution over the same caller boundary. The
facet also owns the shared interpretation of returned and thrown outcomes for
adapters; this classification does not replace or alter the native answer.
Structural descriptions expose wire inputs and complete owner results alongside
their owner-declared normal subsets and progress, without validating trusted
owner values as they flow through execution. Routing composes these descriptions
without narrowing the native return value. Every
described verb's output type is its producing owner's schema output; native
process-local capabilities stay outside that wire description. Each result uses
the native owner's single object answer. Invocation context can
accompany text rendering without being echoed in that answer, and adapters
consume the owner's outcome judgment rather than reconstructing authority from
omitted implementation evidence.

An owner supplies each described verb's business input as one object, including
operations with no business fields. Typed calls and generic execution cross that
same boundary, with the same business inputs and optional execution controls.
Omitted business input has the same meaning on both faces when the operation
accepts an empty input. An amendment's fields are all optional, so both faces
carry a request that names none straight to the Contract owner's unchanged
answer instead of inventing a replacement. Cancellation belongs to execution
rather than business intent; an already-cancelled invocation stops before
coordinate discovery or product observation. After entry, cancellation reaches
native owners that support it without inventing interruption for other
operations. Pure caller constraints
are declared with their producing owner
and checked before coordinate discovery, World establishment, or product
observation; validation never resolves a product merely to judge input shape.
Contradictory caller intent remains usage, distinct from an execution failure.

MCP and Pi publish the facet's operations through one internal model tool
catalogue, subject to the administration and raw-import exclusion owned by
[cli.md](cli.md). Structured output is reserved for routing
operations: it projects normal owner answers onto compact facts needed to choose
the next call. Every normal answer of such a tool carries that projection,
including an answered negative verdict. Native callers and CLI JSON retain the
full owner value. Guidance and Debt detail return complete unclipped text at the
transport edge. These projections supply no new classification or authority.
Error results are text led by their classification and remain text-only, including
their structured failure projection. Runtime recovery guidance uses MCP calls in
MCP syntax, derived from the same native recovery facts used by other surfaces.
An unsatisfied verification verdict is an answered negative, distinct from an
operation failure, and is not a transport error. Published names are safe
for model APIs and are the only callable transport names. Read-only annotations
identify reads; destructive annotations identify destruction alone, not ordinary
writes.

Delivery has one invocation intent, with an explicit read-only observation mode.
The facet validates incompatible observation and mutation intents before resolving
coordinates or observing any product, then selects exactly one native owner.
Observation uses the dedicated Contract preview operation; submission uses native
delivery admission. Both return their existing native answers without an envelope,
and the selected mode supplies presentation context without becoming authority.

Invocation spawn returns birth and optional first Tell admission; invocation tell
returns admission. Neither bundles answer observation. Existing work is observed
through wait, while ask admits structured input and observes its exact answer.
Standalone Akuma and Akumas SDK observation and hosting remain independent
capabilities, not invocation conveniences.

The invocation World is distinct from an explicitly selected Contract Repo:
selecting a Repo never retargets the World. The facet adapts caller-supplied
coordinates, Contract selection, and an optional host Owner supplied once as
invocation identity. The identity is host context, never model business input.
Construction validates and snapshots it synchronously, without reading product
state or altering the captured environment. Invalid or blank identity refuses
rather than falling back. These declarations are not authentication. Akuma
execution directories remain independent of Contract association. Product
surfaces neither depend on the facet nor require it to operate.

A complete environment actor declaration takes precedence over host identity;
otherwise the supplied Owner takes precedence over native environment
attribution. A partial actor declaration is always invalid. Supplied identity
suppresses native host decoding entirely, including inherited or ambiguous host
identities. All caller-dependent operations use this same selection, including
identity observation, caller-scoped listing, creation, and actor-only operations.
At this integration boundary, representable session Owners retain existing
external caller coordinates. Other Owners, including agent-discriminated Owners,
retain their full opaque identity as Square external attribution rather than
collapsing distinct hosts or inventing sessions. Existing durable facts are never
rewritten.

Notification attribution is independent of actor selection. An explicit
nonblank environment redirect wins, followed by the supplied host Owner, then
the existing environment-only recipient selection. An actor never substitutes
its own identity for that recipient. Without supplied identity, environment
fallback behavior is unchanged.

Without supplied identity, ambiguous native harness caller declarations are
refused rather than guessed. The diagnostic names every conflicting environment
variable so the caller can identify the competing declarations without disclosing
their values.

Debt invocation resolves the caller's World independently of a selected Repo.
World-only Debt mutations and Akuma progress reports do not accept repository
selection at the standalone transport edge.
Every Debt catalogue covers that World's flat ledger. Creation alone
establishes a missing World.
Debt reads retain native absence and refusal distinctions, including prerequisite
availability in complete detail; listing defaults to open work.

Each list and addressed status operation selects one producing owner before
observation. The independent selector-free Kanshi read owns the World report;
status requires one complete Contract or Akuma identity or one named selector
and never falls back to World observation. Named status selection reuses the
Address authority and its cross-family collision judgment, freezing the resolved
identity once before exact observation. Later alias movement cannot retarget that
read. Exact selection consults no named authority; native exact-owner operations
remain exact. Selection establishes no World and returns the owner's canonical
identity. A missing Contract is refused; a failed exact Contract read
is an operational failure. Catalogues identify their Contract, Akuma-instance, akumaName, or Debt family even
when empty or unavailable. Contract, Debt, and Akuma-instance catalogues share
active, settled, or complete selection, defaulting to active: still in play versus
at rest. Each product owns its lifecycle classification and retains its own row
vocabulary; invocation never reclassifies it. Lifecycle selection is refused for
akumaName definitions. Instance caller selection remains instance-only and
intersects lifecycle selection before bounding; the remainder describes that
filtered set. Invocation caller
scoping selects only this invocation's effective caller identity; absent or
ambiguous identity is usage. The native Akumas composition independently retains
explicit caller selection. There is no
cross-family catalogue, category status, or plural status result.

Guidance and detail require an explicit selection of one Contract or Debt.
Omission refuses before coordinate discovery or product reads, including inside
a Contract worktree; invocation guidance never infers contextual selection.
Invalid or plural selection likewise refuses before product reads; native Debt
batch reads remain independently owned by Debt.
Kill accepts one selector that may expand to a frozen set of Akumas, preserving
each member's native stop evidence. Named status acquisition belongs to this
shared invocation boundary rather than an adapter-specific route; adapters
supply the selector without resolving it. Invocation waiting composes Contract
journal observation and Akuma work-completion observation without making either
product depend on the other. Each Contract keeps its entry baseline throughout;
a witnessed journal change or terminal observation satisfies that member, while
Akuma satisfaction remains its native completion judgment. Unknown, missing, and
failed observation never establish satisfaction. Native refusal and failure
retain their meaning in the composed answer.

Selection freezes resolved identities once in first-seen caller order, including
native Akuma selector expansion and deduplication. A Contract identity selects
its journal, never its Dispatch roster. One invocation-wide any/all judgment and
one monotonic deadline cover the whole set, including observation reads; already
satisfied members count immediately. A zero deadline still requests an initial
snapshot. Completion takes precedence when witnessed at the deadline edge.
The answer retains ordered, identified native member evidence, including peers
not yet observed when another member satisfies the wait. Neither deadline nor
cancellation stops work; all owned read custody and timers retire before return
or exceptional propagation. Contract-only observation requires no Akuma World.
Native single-family SDK waits remain independent operations with their own
interfaces. Composition retains the Akuma owner's lightweight completion
observation discipline: waiting on unfinished work does not repeatedly load its
full monitoring detail. Returned Contract members include thin journal-derived
summary facts from their witnessed observation, without physical workspace or
target enrichment. Akuma members preserve native life, available activity time
and full exact-turn outcomes; optional association already known to the
observation does not justify new joins. Still-running deadline members retain
a bounded tail of actual recent events from the same observed frontier, with
local unavailability rather than loss of the member's outcome. Waiting is not
a full status read or reported-change observation. History selects one subject. A caller-input error is distinguishable from an owner refusal or
an unexpected failure, and adds no authority to the facet.
